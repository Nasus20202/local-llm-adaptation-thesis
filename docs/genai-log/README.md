# Generative AI Usage Log

This directory records material use of generative AI in accordance with Gdańsk University of Technology Rector's Circular 29/2024. Log significant research, specification, code, analysis, or content generation; do not log trivial autocomplete-like actions.

Each entry records the date, tool/model where known, task, affected artifacts, human verification, and related commit or pull request where applicable. Before thesis submission, verified entries will support the required Polish disclosure and citation material.
