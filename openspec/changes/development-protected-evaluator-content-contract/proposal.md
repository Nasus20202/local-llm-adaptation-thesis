## Why

The approved generic protected-evaluator implementation validates contract identity, criterion roles, evidence identities, deterministic predicate bindings, semantic-assessor routing, and class-specific score configuration. It does not provide validated protected fields for the meaning of a criterion, the meaning of accepted semantic alternatives, observable semantic anchors, unsupported/contradictory claim definitions, or the governed result expected from a deterministic predicate.

The 24 development bundles cannot be constructed scientifically from criterion IDs alone. Adding answer-bearing JSON beside the contract would create an unvalidated parallel schema and would bypass the approved hashing, lineage, model-facing exclusion, and evaluator-loading machinery.

## What Changes

- Extend the existing protected contract schema, rather than creating a parallel bundle format, with answer-bearing protected criterion/alternative/anchor definitions and deterministic expected-result declarations required to make each criterion assessable.
- Validate that every score-affecting criterion has a protected meaning and exact frozen-source evidence mapping; every semantic criterion has an observable anchor; every accepted alternative is defined without canonical-phrase scoring; and every deterministic predicate has an explicit governed result contract where its predicate kind requires one.
- Preserve the existing artifact identity, SHA-256, repository custody binding, append-only events, deterministic-first hierarchy, score kernels, model-facing exclusion, and final-test boundary.
- Keep semantic-judge selection, configuration, qualification, execution, fairness fixtures, participant-model execution, and all final-test work out of scope.

## Scope

This is a software-contract amendment required before authoring the 24 protected development evaluator bundles. It does not add any Kubernetes answer, scenario revision, participant output, judge configuration, qualification label, or final-test material.

## Gate

Human Gate A is required before implementing this amendment or authoring the 24 bundles.
